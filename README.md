# Karthik, Creative Developer Portfolio

Next.js (App Router) · React · TypeScript · GSAP (ScrollTrigger, Flip, useGSAP) · Lenis · Lucide

## Run
```bash
npm install
npm run dev     # http://localhost:3000
npm run build && npm start
```

## Edit
- `data/profile.ts`: set your real email, GitHub and LinkedIn (currently example values).
- `data/projects.ts`: project copy. Images live in `public/assets/projects/`.
